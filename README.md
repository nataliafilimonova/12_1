# 12_1
Домашнее задание к работе 12

Условие задачи (по блок-схеме):
Разработать алгоритм и программу сортировки массива. На вход подается массив arr из n элементов. В результате работы алгоритма элементы массива должны быть отсортированы (судя по условию arr[j] < arr[i], сортировка идет по возрастанию).

1. Алгоритм

1. Начало
2. Задать исходные данные:
   · arr — массив элементов;
   · n — количество элементов в массиве.
3. Запустить внешний цикл: для i от 0 до n-1 (с шагом 1).
4. Внутри цикла задать начальное значение для внутреннего индекса: j = i + 1.
5. Запустить внутренний цикл с условием: пока j >= 0 И arr[j] < arr[i].
   · Примечание: чтобы цикл не был бесконечным, внутри цикла (не показано на схеме, но подразумевается логикой) j должен уменьшаться (j = j - 1).
6. Внутри внутреннего цикла выполнить обмен значений:
   · temp = arr[i]
   · arr[i] = arr[j]
   · arr[j] = temp
7. По завершении всех циклов массив arr считается отсортированным (вывод результата).
